# Multicycle CPU 

## Project Description

This project involved the design and implementation of a **Multicycle CPU** as part of the *EE224: Digital Logic Design* course at **IIT Bombay**. The project was completed in the **3rd semester** under the guidance of **Prof. Virendra Singh**, in a group of four students.

The project was executed in two main phases:

1. **Design Phase**:  
   - Initial pen-and-paper design and structural planning of the CPU.  
   - The design diagrams and structural overview are provided in the file:  
     **`EE_224_CPU_PP`**.

2. **Implementation Phase**:  
   - Writing and testing VHDL code for the Multicycle CPU.  
   - Simulation and implementation were carried out using **Intel Quartus** software.  
   - All source codes are organized in the **`CPU_multicycle/`** folder.

The final report summarizing the work and results is available in the file:  
**`EE224_Final.pdf`**.

For detailed project guidelines and objectives, refer to:  
**`Project-1-Multicycle-RISC-IITB.pdf`**.

## Tools Used
- VHDL
- Intel Quartus Prime
